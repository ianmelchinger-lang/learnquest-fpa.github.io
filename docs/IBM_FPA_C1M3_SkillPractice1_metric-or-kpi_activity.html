Which numbers earn KPI status?

A metric is any number that measures an activity. A KPI is a metric someone has chosen on purpose, because it passes three tests. It is relevant when it ties to a goal the unit is pursuing right now. It is measurable when it has one definition, applied the same way every time, with data available when the report is due. It is actionable when someone owns it and would act differently when it crosses an agreed level.
