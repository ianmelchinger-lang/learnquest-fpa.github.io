Which links earn a place in the tree?

A KPI hierarchy links each driver to the result it affects, so a slipping result traces to the driver that moved first. A link earns a place only when it is real. A link is real when past data shows the lower KPI moving the wrong way before the result falls. A link that only sounds sensible is plausible.

You advise Sample Enterprise Manufacturing (SEM), a fictional manufacturer. The Supply Chain function’s top KPI is the on-time shipment rate. Five drivers are proposed beneath it. For each driver, the history lists four episodes. An episode is a week when the driver moved the wrong way, set beside the week the on-time rate fell.

Mark all five links to check.

Change how much evidence you require

The history stays the same. Change how many of the four episodes must agree. Watch which links change.

SEM is fictional. All weeks and episodes in this activity are invented for practice.
